How It Works

Three steps.
Done.

01
Install globally

One global install via your package manager of choice. Adds the kd binary to your PATH.

npm i -g kerodev
02
Run the wizard

Launch the interactive wizard. Pick your framework, name your project, select addons — all in under a minute.

kd create my-app
03
Start building

Everything is wired. TypeScript compiles. Tailwind loads. Database connects. Just open your editor and write features.

code my-app
